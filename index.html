Architecture Brief / SBT Labs

Multi-store commerce,
one customer profile.

Headless stores that stay swappable by design, feeding unified profiles, journeys, and analytics on Adobe Experience Platform.

Architect  ·  Shravan
01 / The goal

Five topic stores that behave like one brand.

  • Aeds, workfront, aep on Shopify, then fusion, firefly on a custom stack. Room to add more topics later.
  • BOne shared customer profile across every store, so the same learner is recognized everywhere.
  • CEvery action and every order flows into Adobe for journeys and reporting.
  • DBuilt so a change of commerce platform or UI platform is contained work, not a rewrite.
02 / Core idea

Three seams keep it swappable.

Commerce seam

UI talks to one layer

The UI imports a single commerce module. Adapters sit behind it. Config picks the provider per store.

UI seam

Framework-free blocks

All logic in ES modules, every UI piece a decorate() function. Blocks port to EDS, only the shell is throwaway.

Data seam

One canonical order

Any backend emits the same order shape before it reaches Adobe. Schemas and reporting stay stable.

03 / Backends

Two backends behind one UI.

Shopify adapter

eds · workfront · aep

Storefront API for catalog and cart, Customer Account API for auth. Mappers convert Shopify responses to the normalized model.

Custom adapter

fusion · firefly

Pure JS catalog and cart. Checkout and payment through a Worker endpoint. Emits the canonical order with no mapping needed.

Same blocks, same model. The config flag is the only thing that changes per store.

Native accounts, OAuth, passwordless.

  • !Classic password accounts were deprecated in Feb 2026. New stores use New Customer Accounts.

10 / Migration story

Change one thing, not everything.

Swap commerce

Write one adapter

Register it, flip the config. Blocks and pages never know.

Swap UI to EDS

Blocks port over

Scripts and decorate() blocks move as is. Only the shell changes.

Either way

Adobe stays put

Canonical order and schemas are stable, so CJA and AJO keep working.
